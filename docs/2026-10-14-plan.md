# chatgpt-review implementation plan

Goal: 将已确认的上传文件协作流程交付为不同 Agent 可遵循的 skill。

Architecture: 主入口负责角色路由；references 按 ChatGPT、执行端和交换契约分别加载；templates 保存任务与续接记录。可选 Python 标准库 CLI 负责本地任务初始化和自包含审查 ZIP。

Tech stack: Markdown、YAML、Python 3.9+ 标准库。

1. [x] 写入主入口、ChatGPT、执行端、GitHub、备用包契约和六份模板。默认 GitHub 模式，五份任务记录，用户许可及双端续接。
2. [x] 实现 scripts/relay.py，隔离验证两轮 ZIP、实际哈希、证据范围、压缩体积预算、凭据阻断和路径越界。
3. [x] 写 README 和 PROMPTS，首轮派发、同一 PR 审查与新聊天续接均有可复制入口。
4. [x] 最终 quick_validate、17 项工具测试及独立 GitHub/ZIP 场景审查。15 项通过，2 项符号链接限制跳过；验证范围见 VALIDATION。
5. [ ] 生成单文件 ChatGPT 入口，检查公开源码清单并按用户明确的公开发布请求创建和推送仓库。

执行已获用户授权，在当前会话继续。仅工具与测试委派给 worker，其余文件由主 Agent 写入。用户明确授权公开仓库提交与推送，不安装到全局，不发送聊天消息。
